# 近期折腾小记：服务器资源盘点与未来规划

> 日期：2026-07-06

> 分类：折腾

最近又忍不住买机器了，真是手痒，后面打算多跑一些项目，把它们充分利用起来。

目前已经建了三个站，分别分布在亚太、北美和欧洲，不过这三个站我还没想好具体如何去分类，先等我再琢磨一下：
* **亚太节点**：目前是韩国站（使用的是阿里云韩国轻量服务器），将来准备迁移到国内站（机器是阿里云轻量武汉节点）。
* **北美节点**：美东站（使用的是 Netcup RS1000）。
* **欧洲节点**：荷兰站（使用的是 HostDzire）。

再就是之前入手的 OVH 新加坡节点（配置为 4C8G），整体感觉还不错。虽然上面部署了一个 OpenClaw，但目前还没想到太大的用处，感觉有点闲置，等我后续再深入摸索一下。

至于手里各个平台的美国普通线路机器，我计划在上面部署几个轻量级的简单应用，或者用来作为落地节点。比如放一些导航尾页、个人名片等简单的单 HTML 网页，剩下的部分就纯粹作为落地。

关于剩下的线路优化，自然就是拿去拉各种普通线路了。等后面这批机器到期用完后，大部分也就不打算再续费了，转而准备入手一个高性能的亚太服务器，直接搞个 ALL IN ONE，就这样。

最后在想，或许这个博客以后就可以专门用来更新和记录我的这些折腾日常了？
